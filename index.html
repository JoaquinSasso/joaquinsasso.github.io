Key decisionDecisión clave

The vCard QR generator was capped at three fields. With more data the QR got so dense that, on a phone screen, another phone usually couldn't scan it. The tool was later removed, but the reasoning still holds: the constraint came from testing, not taste.

El generador de QR vCard estaba limitado a tres campos. Con más datos el QR quedaba tan denso que, en la pantalla de un teléfono, otro teléfono casi nunca lo podía escanear. La herramienta después se quitó, pero el razonamiento sigue valiendo: el límite salió de probar, no de gusto.

A PC-build advisor where the LLM talks and the code decidesUn asesor de armado de PC donde el LLM conversa y el código decide

A customer describes what they want and their budget in plain language and gets up to three compatible, in-stock builds (~70%, 85% and 100% of budget). Built for an online computer store on Tiendanube.

El cliente describe en lenguaje natural qué quiere y cuánto tiene, y recibe hasta tres armados compatibles y con stock (≈70%, 85% y 100% del presupuesto). Pensado para una tienda de informática en Tiendanube.

What I builtQué construí

  • A deterministic engine that picks parts and checks socket, memory, form factor, GPU length and PSU wattage; property-tested with fast-check, optimized from ~2.3 s to ~115 ms.
  • A money guard: any price in the model's answer that doesn't match a real build gets replaced. Added after I saw Gemini invent prices in a live test.
  • Integrity in the database: a composite foreign key makes it impossible to attach CPU specs to a GPU.
  • An 81-case evaluation (real Reddit/Steam questions + synthetic): 0 price violations, p50 1.7 s / p95 3.0 s.
  • Un motor determinístico que elige piezas y verifica socket, memoria, formato, largo de GPU y potencia de fuente; con tests de propiedades (fast-check) y optimizado de ~2,3 s a ~115 ms.
  • Una guarda de montos: cualquier precio en la respuesta del modelo que no corresponda a un armado real se reemplaza. La agregué después de ver a Gemini inventar precios en una prueba real.
  • Integridad en la base: una FK compuesta hace imposible cargar specs de CPU en una GPU.
  • Una evaluación de 81 casos (preguntas reales de Reddit/Steam + sintéticas): 0 violaciones de montos, p50 1,7 s / p95 3,0 s.

Key decisionDecisión clave

The model never chooses parts. It extracts requirements and explains; tested code decides. When I compared models, the most available one was clearly worse, and a prompt change that lowered scores was rolled back after measuring it.

El modelo nunca elige piezas. Extrae requisitos y explica; decide código testeado. Al comparar modelos, el más disponible resultó claramente peor, y un cambio de prompt que bajó los puntajes se descartó después de medirlo.

How it's built: I design, write the specs and review every change; Gemini agents in Antigravity write most of the code. They reported false results more than once, so I verify everything myself (type checks, greps, manual tests). Not deployed yet and no real users yet.

Cómo se construye: yo diseño, escribo las especificaciones y reviso cada cambio; la mayor parte del código la escriben agentes de Gemini en Antigravity. Reportaron resultados falsos más de una vez, así que verifico todo por mi cuenta (chequeo de tipos, greps, pruebas manuales). Todavía no está desplegado ni tiene usuarios reales.

Reverse-engineering a keyboard with no documentationIngeniería inversa de un teclado sin documentación

A small Python driver that replaces ASUS's official software for the TUF K3 Gen II keyboard and drives a reactive lighting effect, built by decoding its proprietary USB protocol.

Un driver chico en Python que reemplaza el software oficial de ASUS para el teclado TUF K3 Gen II y maneja un efecto de iluminación reactiva, hecho decodificando su protocolo USB propietario.

MethodMétodo

  • Captured USB traffic with USBPcap + Wireshark and mapped each key's hardware ID with a "magic number" technique.
  • Cross-checked packet structure against OpenRGB's behavior, without copying its code.
  • Capturé el tráfico USB con USBPcap + Wireshark y mapeé el ID de hardware de cada tecla con la técnica del "número mágico".
  • Validé la estructura de paquetes contra el comportamiento de OpenRGB, sin copiar su código.

Key decisionDecisión clave

I replaced an OS-level keyboard hook with passive HID reads. Same effect, but it no longer looks like a keylogger to kernel-level anti-cheat software.

Reemplacé un hook de teclado a nivel de sistema operativo por lectura pasiva de HID. El mismo efecto, pero ya no parece un keylogger para los anti-cheat de kernel.

Funciona 100% offline, con sincronización y respaldo opcional en Google Drive. El alfabeto de 26 caracteres excluye los dos miembros de cada par que se confunde a mano (I/1, O/0, Z/2, S/5, B/8). Descarté un prototipo con WorkManager porque el Doze mode lo volvía impredecible.

Backtesting engineMotor de backtesting

Tested 15 trading strategies on data from 2010 on. Sped the engine up from 361 s to 4.4 s with identical trades to the cent, and tracked every variant tried to control overfitting. Result: none beat the S&P 500. An AI news-veto module never vetoed anything, so I turned it off.

Probé 15 estrategias bursátiles con datos desde 2010. Aceleré el motor de 361 s a 4,4 s con trades idénticos al centavo, y registré cada variante probada para controlar el overfitting.
